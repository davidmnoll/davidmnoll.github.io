A type can be considered as a set.  Some sets are finite like the Boolean type { True, False }.  Some are infinite like the set of natural numbers. 

In order for us to computationally represent a type of infinite cardinality, we must generally rely on some form of inductive or coinductive structure. 

We can represent this in different ways.  Recursion is one way.  The peano construction of the natural numbers uses 0 as the base case, and gives you "successor" as a unary function
